# Ai classification

## Описание📎

Ai classification - Это ии которое классифицирует изоброжения собаки и кошки оно может их разлечить и сказать где собака а где кошка 

## Технологии 🚀
- Python 3
- CV2
- Tensorflow
- matplotlib


## Устоновкаи запуск 🛠️

1. **Клонируйте репозиторий**
2. **Создайте Виртуальную окружение**
3. **Устовнока плагинов**
- Tensorflow
- CV2
- matplotlib

4. **Установка Картинок для обучение ии 20+ картинок желательно 50 - 70 можно больше**
5. **Картинки нужно закинуть а папку Dataset которую нужно будет создать и уже в папке Dataset нужно создать две папки папку dogs и cats и в эти папки закинуть картинки кошек в папку cats и картинки собак в папку dogs**

6. **Запустите сервер🔋**
